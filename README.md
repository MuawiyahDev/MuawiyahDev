## Engineering Principles

- Keep responsibilities explicit and architectural boundaries clear.
- Build reusable components without unnecessary abstraction.
- Enforce authorization and data integrity on the backend.
- Treat database design and tenant isolation as first-class concerns.
- Prefer reliable, understandable solutions over unnecessary complexity.
